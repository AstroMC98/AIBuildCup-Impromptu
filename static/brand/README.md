# Brand

Copied unchanged from the Impromptu brand kit (`assets/impromptu-brand-kit`, generated by its
`source/build_brand.py`). To change the logo, regenerate the kit and copy the files again.

| File | Used for |
|---|---|
| `impromptu-horizontal-on-light.svg` | The logo in the house with the lights up (the `--logo` token) |
| `impromptu-horizontal-on-dark-glow.svg` | The logo in the house with the lights down, on the stage, and in the boot ident |
| `impromptu-horizontal-mono-white.svg` | The logo on a pod's cover in Now playing |
| `favicon.svg`, `favicon.ico` | Browser tab icon (the `.ico` is also served at `/favicon.ico`) |
| `apple-touch-icon-180.png` | iPhone and iPad home screen |
| `pwa-192.png`, `pwa-512.png` | Android home screen, via `manifest.json` (the mark sits inside the maskable safe zone) |
| `og-image-1200x630.png` | Link previews (`og:image`; the server makes its URL absolute) |

The glowing logo's file has 40 extra units of room for the glow on every side of a logo
389.81 units tall. `--logo-bleed` lets it spill past the logo's box by that much, so both
artworks take the same space on the page.
